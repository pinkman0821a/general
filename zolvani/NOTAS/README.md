# Notas técnicas de Zolvani

Esta carpeta contiene notas Markdown que pueden abrirse como cuaderno local en QOwnNotes. No guarda la base interna de QOwnNotes ni modifica su configuración global. Para usarla: en QOwnNotes, añade `Z:\Zolvani\NOTAS` como carpeta de notas existente.

Las tareas de desarrollo deben gestionarse en Beads (`bd`), cuando su base local pueda inicializarse. Estos documentos registran decisiones, estado y resultados; no sustituyen el tablero de trabajo.

No guardar aquí credenciales, claves, tokens ni datos reales de clientes.
