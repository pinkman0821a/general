# Entrega preliminar — Zolvani Colmena

Se entrega un ZIP instalable con una aplicación **local y de simulación**. Se desarrolló una base independiente que deja funcional el flujo visual de Reina → huevo → abeja → Inspectora → entrega. La Colmena 3D reacciona al estado de cada agente durante la ejecución simulada.

Para iniciar, ver `README.md`. Para consultar progreso exacto y pruebas, ver `ESTADO_PROYECTO.md`. Para dar continuidad a Codex, ver `AGENTS.md` y `ROADMAP.md`.

**Lo que NO sería correcto afirmar:** que ya está conectado a IA, que registra pedidos en Dropi, que publica en redes, que accede a productos reales, o que es un fork descargado de Agentes_IA_3D.
